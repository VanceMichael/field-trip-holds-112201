# 来源接口

在浏览器打开 /workshop 或 /shuttle。可见表格显示场次号、到离时刻、站点、成人和儿童余量。工坊可容纳的成人和儿童名额分开，接驳的两类计入共同座位池，表格中的数是池内面向每类的当前上限。
表单使用领队提供的联络号作为双方都能查到的备注。成员一行一个，格式为成员号、英文逗号、adult 或 child。第二张表单按联络号查询，可见回执包含受理单、受理成员、可释放截止时刻和当前有效时刻。两处服务都允许凭显示的受理单释放。门户只受理本地练习占位，生成的受理单没有支付功能。
业务输入以户为单位，同行户只有完整同行才符合授权。缓冲是完成接驳到达至工坊开场至少所需分钟，时间上限约束到工坊结束。自有车授权项单独提供到场时刻。
